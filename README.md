# Theatre Animator

Historically careful animations of ancient Greek theatre and thought. Each element on screen is drawn to show how sure we are of it: attested by ancient texts, inferred by scholars, or reconstructed by us. See `shared/STYLE.md`.

## Animations

| Slug | Subject | Status |
|---|---|---|
| `animations/ekkyklema` | The ekkyklema, the platform rolled out to reveal interior scenes | Research and storyboard approved; build in progress |
| `animations/ajax-ekkyklema` | The ekkyklema in Sophocles' *Ajax* (346–595) | Planned |

## Each animation folder
- `NOTES.md`: research questions and the primary passages checked
- `SOURCES.md`: ancient and modern sources, with findings tagged [A] attested, [I] inferred or [R] reconstruction
- `STORYBOARD.md`: beats, timings, captions, and the reconstruction choices
- `layout.svg`: true-scale layout draft
- `index.html`: the finished interactive animation
